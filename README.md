# Student Dashboard

A simple student dashboard built with HTML, CSS, and JavaScript to help students track their courses and learning progress in one place.

## Description

Student Dashboard is a clean, beginner-friendly web page that shows a student's enrolled courses, progress bars, and quick stats on a single dashboard. It was built as a Git & GitHub capstone project to demonstrate a complete version-control workflow: initialization, branching, pull requests, code review, and CI with GitHub Actions.

## Features

- Dashboard overview with student info and quick stats
- List of enrolled courses with progress bars
- Course cards showing instructor and completion status
- Clean, responsive layout
- Lightweight — no frameworks or build tools required

## Technologies Used

- **HTML5** — page structure
- **CSS3** — styling and layout
- **JavaScript** — dynamic content and interactivity
- **Git & GitHub** — version control, branching, pull requests, code review, GitHub Actions

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/ahmedfaarax7605-creator/-Portfolio.git
   ```

2. Open the project folder.
3. Double-click `index.html` (or open it in any web browser).

No installation or server is needed — the project runs directly in the browser.
